سياسة الأمان

الإجراءات التقنية لحماية بياناتك وأموالك على منصة الفضل للاتصالات

تشفير الاتصالات

كل الاتصالات بين جهازك والمنصة مشفرة ببروتوكول TLS HTTPS/TLS
HTTP Strict Transport Security — نلزم المتصفح باستخدام الاتصال المشفر HSTS
شهادة SSL صادرة من جهة معتمدة SSL

حماية الحسابات

كلمات المرور مشفرة بخوارزمية bcrypt — لا يمكن لأحد قراءتها حتى الإدارة bcrypt
رمز تحقق لمرة واحدة عبر البريد الإلكتروني للمعاملات الحساسة (التسجيل، التوقيع) OTP
قفل مؤقت بعد عدة محاولات دخول فاشلة — على مستوى الحساب والـ IP Rate Limit
جلسات محميّة بـ HttpOnly + Secure + SameSite + انقضاء تلقائي Session
توثيق ثنائي إلزامي (جوال + بريد) قبل توقيع العقود 2FA

حماية المعاملات المالية

  • بوابة MyFatoorah: بوابة دفع إلكترونية معتمدة للتعامل في المملكة العربية السعودية — بيانات البطاقات لا تُخزّن على خوادم المنصة.
  • المطابقة البنكية: كل حوالة بنكية تُراجع وتُطابق مع كشف الحساب البنكي قبل الاعتماد.
  • CSRF Protection: كل عملية مالية تتطلب رمز أمان لمنع التلاعب بالحساب.
  • Audit Trail: سجل تدقيق مفصل لكل عملية مالية يشمل المستخدم، التاريخ، المبلغ، وعنوان IP.
  • التحقق المزدوج عند التوقيع: يتطلب رمز OTP + تسجيل الدخول لتأكيد وتوثيق التواصل.

حماية البيانات المخزّنة

  • قاعدة البيانات محمية بكلمة مرور قوية وصلاحيات محدودة على مستوى الخادم.
  • النسخ الاحتياطية تتم بشكل دوري وفق سياسة مزود الاستضافة.
  • الملفات المرفوعة (مثل إيصالات الدفع) مخزّنة خارج المجلد العام ولا تُقدّم للوصول المباشر.
  • البيانات البنكية (الآيبان) تُستخدم حصراً لتحويل مستحقات المستخدم.

حماية التطبيق

كل المخرجات منقاة بـ htmlspecialchars لمنع حقن السكريبتات XSS
كل الاستعلامات تستخدم Prepared Statements (PDO) SQL Injection
رمز أمان فريد لكل نموذج وعملية POST CSRF
X-Frame-Options + X-Content-Type-Options + Referrer-Policy + HSTS Headers
فلترة الملفات المرفوعة بـ extension و MIME و imagesize — رفض أي ملف تنفيذي Upload Filter
